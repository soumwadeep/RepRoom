Amazon Bedrock.

What it does: exactly one thing - it turns a set of measurements into a single sentence of coaching. It is deliberately outside the counting path and outside the form-grading path, because a rep count has to be reproducible for the benchmark to mean anything and a generative model should not be the thing deciding whether a repetition happened.

How it is integrated: services/coach/coach.py calls the bedrock-runtime Converse API with a system prompt that forbids introducing any figure not present in the input (temperature 0.3, 160 max tokens). The prompt payload comes from session_facts(), which drops every form check whose status is "not_measurable" so the model is never handed a null and invited to interpret it. Model selection is discovered at runtime rather than hardcoded, because Bedrock availability is per account and per region and cross-region inference profiles carry their own identifiers: discover() calls ListInferenceProfiles, and where an account has no profile it falls through to ListFoundationModels plus GetFoundationModelAvailability, reporting a PENDING agreement as what it actually is - the one-time Anthropic use-case form - rather than as a permissions mystery.

Honest status of the claim: the cue endpoint, its caching, the provenance labelling and the failure paths are tested, and the failure path was exercised against the live AWS endpoint - an invalid-credential probe reached Bedrock, returned UnrecognizedClientException, the service surfaced that as the cue's reason and degraded to a labelled rules line. A successful model completion has not been run, because the account's Bedrock API key was not configured on the build machine at submission time. No number in this submission is attributed to Bedrock, and the integration will be verified and the entry edited before the deadline.

Design detail that matters for cost and for the demo: every cue carries its source and the television renders it - "COACH . BEDROCK . <model id>" versus "COACH . BUILT-IN RULES". A rule assembled from an if-statement and a generated sentence are not the same claim, and the viewer is entitled to know which one is on the wall. Caching is per (exercise, rep count, failed checks), so a TV polling several times a second does not spend a model call per poll.

The permissions the integration needs are in infra/bedrock-cue-policy.json: Bedrock read actions for discovery, bedrock-runtime InvokeModel scoped to Anthropic models and inference profiles, and the three aws-marketplace actions Bedrock requires the first time a model is enabled in an account.
